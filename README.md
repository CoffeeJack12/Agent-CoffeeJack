# CoffeeJack

مساعد شخصي محلي على Windows: محادثة بالعربي والإنجليزي، ذاكرة دائمة، أدوات برمجة وملفات ومتصفح، ووضع ألعاب.

## التشغيل على هذا الجهاز

1. افتح **Start CoffeeJack.cmd**. تظهر الواجهة على http://127.0.0.1:3210.
2. افتح **Open in Cursor.cmd** للعمل على الكود في Cursor.
3. لإيقاف التطبيق وتفريغ الموديلات، افتح **Stop CoffeeJack.cmd**.

المحرك والموديلات وNode والمتصفح موجودة داخل `.runtime/` محليًا، ولا تُرفع إلى GitHub. ملفات التشغيل لا تحتاج Node مثبتًا على مستوى النظام في هذا الجهاز.

## ما يعمل

- محادثات محفوظة في SQLite مع ردود تظهر أثناء التوليد.
- ذاكرة قابلة للبحث والإضافة والحذف: تفضيلات وحقائق ودروس؛ ليست تدريبًا لأوزان الموديل.
- أدوات قراءة وإنشاء الملفات؛ نسخ احتياطية عند استبدال ملف موجود.
- تشغيل PowerShell، مدير حزم Node، Git، وإعادة المحاولة حسب أخطاء الأدوات، بحد 16 جولة لكل طلب.
- متصفح Chromium معزول للبحث والقراءة والضغط وتعبئة الحقول ولقطات الشاشة.
- قراءة النصوص وPDF النصي وDOCX وXLSX، ورفع ملفات حتى 20 MB.
- اختيار موديل للمحادثة والبرمجة والصور؛ توجيه الصور للموديل البصري في الوضع التلقائي.
- أدوات Windows لالتقاط الشاشة والضغط والكتابة واختصارات المفاتيح. هذه الأدوات تتطلب جلسة سطح مكتب تفاعلية وموديل رؤية للتعامل مع الصورة.
- سجل محلي لنتائج الأدوات، موافقة على التنفيذ، وإيقاف المهمة الجارية.
- وضع ألعاب يدوي وتلقائي للأسماء المحددة في الإعدادات: يوقف المهمة، يغلق متصفح الأتمتة ويفرغ الموديلات المحملة. يعود لاستقبال الطلبات بعد إغلاق اللعبة؛ لا يستأنف أمرًا مقطوعًا تلقائيًا.
- واجهة عربية متجاوبة، نصية بالكامل، دون ميزات صوت.

## الموديلات

الإعداد المحلي يستخدم `qwen3:8b` للمحادثة والبرمجة و`qwen3-vl:8b` للصور، عبر Ollama. لا يحتاج اشتراكًا أو مفتاح API. الإنترنت مطلوب لتنزيل الموديلات ولأدوات الويب، بينما المحادثة والذاكرة تعملان دون الإنترنت بعد التنزيل.

الجهاز الذي جرى إعداده: RTX 4070 Ti بذاكرة 12 GB، وRAM بسعة 32 GB. يسمح التشغيل بموديل محمل واحد في الوقت نفسه، وبنافذة سياق 8192. جودة العربية والبرمجة والتحكم تعتمد على الموديل المحلي؛ لا يوجد ضمان لتنفيذ أي مشروع أو أي تطبيق دون أخطاء.

## الخصوصية والصلاحيات

الخادم مربوط بـ`127.0.0.1`، مع فحص Host وOrigin ورمز جلسة للكتابة. لا تفتحه مباشرة على الإنترنت. المحادثات والذاكرة وملفات المستخدم وجلسة المتصفح داخل `.local/` ومستثناة من Git. يبدأ وضع الموافقة اليدوية مفعّلًا؛ يمكنك تفعيل التنفيذ التلقائي من الإعدادات.

أدوات الملفات مقيدة بمساحة العمل وتفحص الروابط الرمزية، لكن **PowerShell والتحكم بسطح المكتب ليسا صندوقًا معزولًا**: عند الموافقة يمكنهما الوصول إلى موارد المستخدم خارج هذا المجلد. الذاكرة والسجل محفوظان محليًا دون تشفير إضافي؛ استخدم حماية حساب Windows وBitLocker عند الحاجة. ملفات PDF الممسوحة تحتاج مسار صور/OCR، ولا تستخرج النصوص من كل PDF بالضرورة.

## نسخة جديدة من GitHub

المستودع يحتوي الكود وملف قفل الحزم فقط. على جهاز آخر: ثبّت Node 24+ وpnpm وOllama، ثم:

```powershell
pnpm install --frozen-lockfile
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path $PWD '.runtime\browsers'
pnpm exec playwright install chromium
ollama pull qwen3:8b
ollama pull qwen3-vl:8b
pnpm start
```

اختر الموديلات من الإعدادات. على Windows، ملف `scripts/start.ps1` يجهز المسارات ويشغل الخدمات. متغيرات البيئة موضحة في `.env.example`؛ إذا استخدمت ملف `.env` شغل `node --env-file=.env server/index.mjs`، لأن التطبيق لا يقرأه تلقائيًا.

## التطوير والتحقق

```powershell
pnpm test
pnpm run check
```

أو على هذا الجهاز: `.\.runtime\node.exe --test tests/*.test.mjs`.
