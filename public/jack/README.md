# Jack branding

Place your approved PNG files here: `avatar.png`, `icon.png`, `logo.png`. They are optional; the reusable `public/branding.js` component shows a J monogram when missing. Avatar is used in assistant messages and personality previews, logo in the sidebar, icon for the welcome and browser tab. Keep images reasonably small (under 1 MB recommended). No portrait is generated or downloaded. Reload the page after replacing assets.
